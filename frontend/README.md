# Bazaar
A mock e-commerce shopping cart for [The Odin Project](https://theodinproject.com). Product data from [Fake Store API](https://fakestoreapi.com).

## Built With

- React
- TypeScript
- Vite
- React Router
- Vitest
- React Testing Library

## Features

- Browse, search, and filter products by category
- View individual product details and adjust quantity before adding to cart
- Cart persistence via localStorage

## Installation
* `git clone https://github.com/jetfuzz/shopping-cart.git`
* `cd shopping-cart`
* `npm install`
* `npm run dev`
